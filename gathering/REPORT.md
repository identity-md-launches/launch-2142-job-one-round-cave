## Shared handoff

Added `shared/merge-citations/candidate_citations.py`, joining line 1's Candidate Additions with line 3's Citation Ledger for a **separately supplied candidate tree**. It first verifies saved anchors against the base, then checks both branch additions and the candidate's current citations, and finally rereads all four trees and the ledger. A missing cited file is a review row. It does not apply or approve a merge. The line 1 module was copied byte for byte into the portable bundle and pinned in `PROVENANCE.json`; the existing copied Ledger and tree reader remain in place. No line folder is needed at runtime.
